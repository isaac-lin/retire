# 退休水位

逐年模擬你的退休資產水位，算出**資產見底的年齡**與**最早可退休年齡**。

純靜態網頁，所有計算都在瀏覽器內完成——沒有後端、沒有資料庫、沒有追蹤碼，你填的任何數字都不會離開你的裝置。

## 它回答什麼

輸入年齡、資產、月存、退休後月支出與市場假設，頁面上方那條長條圖就是你的一生：一年一根柱，高度是那年年底的資產。

- **墨綠**　累積期
- **墨黑**　提領期
- **朱紅**　資產見底之後的赤字年

同時給出三個數字：資產見底年齡、以現在的存法最早能在幾歲退休、以及若要維持原訂退休年齡、每月得多存多少。

## 針對台灣的設定

- 金額單位一律為**萬元**（新台幣）
- 「退休後其他月收入」欄位用來填**勞保年金＋勞退月退**，可自訂請領年齡（預設 65 歲）
- 累積期與退休後的報酬率分開設定，反映退休後多數人會把部位轉保守
- 附 4% 法則對照值作為檢查點

## 計算方式

以「年」為單位，從現在年齡跑到 100 歲。每年先讓期初餘額生一年報酬，再加上當年投入（累積期）或扣掉當年淨支出（退休後）。支出與年金皆隨通膨逐年放大，因此輸入時使用**今天的物價**即可。「資產見底」是餘額第一次轉負的那一年。

**沒有計算的項目**：所得稅、健保與長照支出、重大醫療、房貸、不動產、繼承、子女教育金。模擬使用固定報酬率，未處理報酬順序風險（退休初期遇上大跌的衝擊）。
